GOLD TRACKER NATIVE ANDROID — SOURCE PROJECT

Ini adalah aplikasi Android native (Activity Java + SQLite), bukan WebView/PWA.
Fitur versi awal:
- Dashboard statistik per bulan: trade, WR, WIN/LOSS, net pips.
- Input manual tanggal, BUY/SELL, TP/WIN atau SL/LOSS.
- TP tetap +303 pips dan SL tetap -303 pips.
- Maksimal 50 trade per bulan.
- Riwayat trade dan hapus catatan.
- Simulasi ekspektasi WR 55/60/65/70/75/80%.
- Database SQLite lokal di HP.

Belum ada APK yang dikompilasi di paket ini. Build otomatis disiapkan melalui GitHub Actions.
Cara dari HP:
1. Buat repository baru di GitHub melalui browser.
2. Upload seluruh isi folder proyek ini ke repository (jangan upload ZIP sebagai satu file; ekstrak dahulu).
3. Buka tab Actions, aktifkan workflow bila diminta.
4. Jalankan workflow "Build Gold Tracker APK" dengan Run workflow.
5. Setelah selesai, buka hasil run dan unduh artifact "GoldTracker-APK" (ZIP berisi app-debug.apk).
6. Ekstrak ZIP lalu instal app-debug.apk di Android.
Catatan: APK debug cocok untuk instalasi pribadi/testing. Jangan membagikan APK ke publik sebagai rilis resmi tanpa proses signing release yang dikelola dengan aman.
